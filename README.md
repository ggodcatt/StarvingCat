# 🐱 Starving Cat Project 🐟
<img width="1000" height="600" alt="IntroScreen" src="https://github.com/user-attachments/assets/63cc10d7-9485-4242-b1fa-7bfd76b4ca32" />  <br/>
Starving Cat Project เป็นโปรเจคกลุ่มที่มีสมาชิกทั้งหมด 4 คน โดยเกมนี้ได้รับแรงบันดาลใจมาจากเกม Pac-Man กลุ่มของเราได้พัฒนาให้มีความแปลกใหม่และน่าสนใจมากยิ่งขึ้น โดยมีหลายแมพให้ผู้เล่นสามารถเลือกเล่นได้ อีกทั้งยังมีการปรับตัวละครและฉากในเกมให้มีความดึงดูดใจมากขึ้น นอกจากนี้ แต่ละแมพยังมีกติกาการเล่นที่แตกต่างกันออกไป เพื่อเพิ่มความท้าทายและความสนุกสนาน เกมนี้ถูกพัฒนาขึ้นโดยใช้โปรแกรมเชิงวัตถุ (Object-Oriented Programming)<br/>
